# 📌 Homit
> "커뮤니티 기반 생활비 절약 플랫폼"

---

## ✨ 프로젝트 소개
- 사용자들이 공동구매 참여, 나눔, 요리 레시피 제공, 커뮤니티 작성, 리뷰를 남길 수 있는 커뮤니티 기반 플랫폼입니다.

---

## 🛠 사용 기술 (Tech Stack)
- Frontend : React, React Router
- Backend : Spring Boot 3.4, Spring Security, JPA, JJWT, WEBSOCKET, STOMP 
- Database : MySQL
  
---

## 👥 팀원 소개
| 이름 | 역할 | 담당 기능 |
|:---|:---|:---|
| 정범준 | 팀장 / 프론트엔드 |  |
| 태형 | 프론트엔드 | 메인페이지, 로그인/회원가입페이지, 마이페이지, 요리레시피, 동네톡 |
| 승빈 | 백엔드 | DB 설계, API 기능명세서, WebSocket, 회원관리 및 로그인(Spring Security, JWT, OAuth2 소셜로그인), 마이페이지, 인기상품(네이버 쇼핑 API), 상품 위시리스트, 레시피 즐겨찾기, 데이터 변환 로직 설계, 댓글/좋아요 |
| 순화 | 벡엔드 | 커뮤니티/공동구매/나눔 CRUD 및 이미지 연동, 공동구매 신청자 관리 로직 및 상품 구매, 데이터 변환 로직 설계|

---

## 🔥 주요 기능
- 회원가입 / 로그인
- 공동구매 등록 / 수정 / 삭제 / 참여 / 상품 구매
- 나눔 게시판(글 작성/수정/삭제/사진 업로드)
- 커뮤니티 게시판 (글 작성/수정/삭제/사진 업로드)
- 댓글 및 좋아요 기능
- 요리 레시피 조회 기능 및 즐겨찾기 기능
- 네이버 쇼핑 API 기반 인기상품 검색 기능
- 마이페이지
- 공동구매 인플루언서 소개 기능
- 공동구매 인기 Shorts 시청 기능(유튜브)
