# 📌 Homit
> "커뮤니티 기반 생활비 절약 플랫폼"

---

## ✨ 프로젝트 소개
- 사용자들이 공동구매 참여, 나눔, 요리 레시피 제공, 커뮤니티 작성, 리뷰를 남길 수 있는 커뮤니티 기반 플랫폼입니다.

---

## 🛠 사용 기술 (Tech Stack)
- Frontend : React, React Router
- Backend : Spring Boot 3.4, Spring Security, JPA, JJWT, WEBSOCKET, STOMP 
- Database : MySQL
  
---

---

## 🔥 주요 기능
- 회원가입 / 로그인
- 공동구매 등록 / 수정 / 삭제 / 참여 / 상품 구매
- 나눔 게시판(글 작성/수정/삭제/사진 업로드)
- 커뮤니티 게시판 (글 작성/수정/삭제/사진 업로드)
- 댓글 및 좋아요 기능
- 요리 레시피 조회 기능 및 즐겨찾기 기능
- 네이버 쇼핑 API 기반 인기상품 검색 기능
- 마이페이지
- 공동구매 인플루언서 소개 기능
- 공동구매 인기 Shorts 시청 기능(유튜브)

<details>
  <summary>💵 수익 구조 (Revenue Model)</summary><br>
	1. 판매수수료(커미션) <br><br>
	•	기본 구조: 셀러랑 협의를 통해 사이트 운영진이상품을 등록하고, 판매가 이루어질 때마다 일정 비율의 수수료를 금액 정산 단계에서 사이트가 가져가는 방식입니다. <br>
	•	수수료율: 상품군, 셀러 역량, 마케팅 방식에 따라 다름 <br>
	•	정산 방식: 판매 완료 후 자동 정산이 일반적이며,  셀러별로 차등 수수료를 적용도 생각중 <br>
	2. 광고 및 배너 수익 <br><br>
	•	광고 배너: 사이트 내 메인화면, 상품 리스트 배너 광고를 유치해 월 단위로 광고비를 받거나 공동구매 오픈 기간별로 받습니다. <br>
	•	광고 단가: 월 10만~50만 원 수준 <br>
	•	핫딜/프로모션 배너: 특정 상품이나 셀러의 핫딜을 메인에 노출해주는 대가로 추가 광고비를 받는 구조 <br>
	3. 핫딜/프로모션 <br><br>
	•	핫딜 프로모션: 특정 기간 동안 한정 수량, 특별 할인 등으로 공동구매를 진행하고, 별도의 프로모션비를 셀러에게 받는 방식입니다. <br>
	•	운영 방식: 커뮤니티, 인플루언서와 협업해 바이럴 마케팅, 체험단, 리뷰 이벤트 등과 연계할 수 있습니다. <br>
	•	수익 구조: 운영진이나 플랫폼이 매출의 일정 부분을 수수료로 받거나, 별도의 프로모션비(고정/성과형)를 받습니다. <br>
	4. 기타 부가서비스 <br><br>
	•	배송/사후관리: 배송 대행, 사후관리 등 부가서비스를 유료로 제공해 추가 수익을 창출할 수 있습니다. <br>
</details>
